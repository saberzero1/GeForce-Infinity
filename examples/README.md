# Nix Examples

This directory contains example configurations for using GeForce Infinity with Nix.

## Available Examples

### flake-with-geforce-infinity.nix

A complete example showing how to integrate GeForce Infinity into your NixOS configuration using flakes. This example demonstrates:

- System-wide installation using the NixOS module
- Optional Home Manager integration
- Required hardware and audio configuration
- Best practices for Nix flake structure

## Usage

1. Choose the example that matches your setup
2. Copy the relevant parts to your own configuration
3. Adapt the configuration to your needs (hostname, username, etc.)
4. Rebuild your system or Home Manager configuration
